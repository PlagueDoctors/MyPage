页面脚本没有加载成功

本项目的 index.html 是构建工具的源码入口，必须先构建成 dist/ 再发布。如果 GitHub Pages 的 Source 被设成了 Deploy from a branch → main / (root)，它会把源码目录直接当站点发布， 浏览器就会因为 /src/main.ts 的 MIME 类型不是 JavaScript 而拒绝执行。

修复方式：仓库 Settings → Pages → Build and deployment → Source 选择 GitHub Actions，然后重新运行 Deploy 工作流。

本地预览：npm install && npm run dev
